About QuickNotes

QuickNotes is a simple app for writing down ideas, reminders and to-do lists. It helps you keep all your notes in one place so you can find them quickly.

How to use QuickNotes

  1. Open the QuickNotes home page.
  2. Type your note in the text box.
  3. Click the Save button.
  4. Find your saved note in the list below.

Features

  • Create notes quickly
  • Edit and delete notes
  • Search through your notes
  • Works on phone and computer

Keyboard shortcuts

Shortcut Action
Ctrl + N Create a new note
Ctrl + S Save the note
Ctrl + F Search notes
